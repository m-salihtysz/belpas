# Tesis Görselleri / Photos Folder

Tesisleriniz için görselleri bu klasöre ekleyebilirsiniz (`public/images/tesisler/`).

Örnek dosya isimlendirmeleri (slug veya tesis adına uygun):
- `ormanpark.jpg` (veya `.png`, `.webp`)
- `acarlar-longozu.jpg`
- `cark-i-dem.jpg`
- vb.

Görselleri buraya yükledikten sonra tesis kartlarına veya detay modallarına otomatik/dinamik bağlama yapabiliriz.
